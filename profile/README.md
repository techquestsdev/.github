# Tech Quests

> SRE rabbit-holes, homelab adventures, and platform engineering experiments.

Tech Quests is a content brand by [Andre Nogueira](https://github.com/aanogueira)
(`aanogueira`) — a Portugal-based Site Reliability Engineer. It collects the technical
work that doesn't fit on a CV: long-form blog posts, hands-on projects, and short
videos on infrastructure, reliability, and platform engineering.
